# GuanyiSearch IP 绘画语法

> 这是一份未来创作的审美约束，不是一套已经验收的图标库。未经单独审稿，不把任意线稿当作生产资产或对外素材。

## 0. 先分清两种语言

### A. 陈纸功能线绘：用来说明

适用于钱包卡片、奖励入口、客服入口、空状态和流程说明。现有礼盒、Coins、购物车、嫩芽属于这类。

- 目标是让人**立刻理解功能**。
- 主物件可被清楚辨认；线条克制，颜色承担状态提示。
- 使用墨线 `#1F1F1B`、陈纸 `#F3EDE0`、鼠尾草、黄铜、陶土橙。
- 可以有轻地面线，但不画阴影、材质、高光或渐变。

### B. 墨黑签名主视觉：用来建立气质

适用于仪表板英雄区、活动封面、品牌故事、重要公告和高关注营销图。它参考的是“图 2”那种能在黑底上独立站住的**笔势化主视觉**。

- 目标不是说明一个对象，而是先传递**人的动作、关系或情绪**。
- 不是把浅色功能线绘换成白线；每一张都要从概念重新构图。
- 必须具有一个大而独特的手势轮廓；观者应先感到节奏，再读懂隐喻。
- 白线、留白和一个颜色体块共同构成画面；不要 UI 图标、卡片框或完整说明文字。

两种语言可以共用色板，但不能共用构图方法。把 A 直接反相成 B，会得到“线稿图标”，而不是有品质的黑底主视觉。

## 1. 为什么现有黑底笔记本不够好

黑底笔记本能读懂“问卷”，但还停留在功能图标层级，和参考主视觉不在一个完成度上：

1. **叙事过满**：线圈、外框、三组方框、三条文字线、笔、地面线都在争夺注意力。
2. **笔势太平均**：所有轮廓同样细、同样理性，像 SVG 描边，没有一个能成为画面记忆点的动作。
3. **颜色只是在填空**：黄、绿、橙分散出现，像状态标签，而不是一个有重量的色彩主体。
4. **轮廓过于封闭**：完整方形纸张和整齐重复的清单格，削弱了黑底应有的开放感和留白张力。
5. **动效是附加项**：轻微漂移并不能提升图形本身；图形必须静止时就成立。

因此，现有黑底笔记本只作为一次探索记录，不作为以后黑底主视觉的质量基准。

## 2. 墨黑签名主视觉的构图语法

### 2.1 从“动作”而不是“物件”开始

先把内容写成一个人本动词，再寻找形状：

| 内容 | 不要从 | 应从 |
| --- | --- | --- |
| 问卷 | 表格、勾选框、笔 | 落笔、确认、被认真记录 |
| Coins | 硬币叠放 | 积累、环绕、价值被看见 |
| 兑换 | 礼盒、购物车 | 交付、抵达、被感谢 |
| 客服 | 聊天气泡、三个点 | 倾听、回应、连接 |
| 隐私 | 盾牌、锁 | 守护、边界、由自己掌握 |

先画至少三张黑白小草图，只保留最有辨识度的一张；不要一开始就往画面里塞功能部件。

### 2.2 主笔势

以 `1080 × 1080` 为基准：

- 用一条或两条**大笔势**占据约 `55–70%` 的活动区域；线宽可到 `22–32px`，而不是功能线绘的 `8–12px` 等比放大。
- 笔势应有进入、停顿、转折和离场：像一次真实落笔，而不是由多个等宽图标线段拼出来。
- 主笔势可以被画布边缘自然裁切；不必把对象完整关进框里。
- 允许局部明显加粗、收细或留出断口；但每张图只保留一种可读的节奏。
- 圆角端点必须饱满，曲线需要长而干净的 Bézier 控制，不使用短促折线模拟手绘。

### 2.3 留白与比例

- 墨黑底使用 `#151514`，大面积保持纯净；不要纸纹、网格、渐变或灰色卡片。
- 主图形不要居中做“图标陈列”。推荐偏左、偏下或跨边缘，让留白成为构图的一部分。
- 一幅主视觉只允许一个英雄轮廓、一个色彩主体和至多两条次要支线。
- 画面在缩小到 `160px` 时，应先看见轮廓和色块，而不是一堆细节。

### 2.4 色彩不是点缀，而是重量

- 深色版以陈纸白 `#F7F0E3` 为主笔势；不使用普通灰线作为主轮廓。
- 只选**一个**高辨识色彩体块：优先陶土橙 `#C76F43` 的圆、椭圆或不规则色面。
- 鼠尾草 `#8F9E7B` 或黄铜 `#D7AE62` 仅在确有语义时作为第二色；不要同时出现三个小色块。
- 色块可以压住或穿过白线的一部分，形成前后关系；不要每块色都加边框。
- 色块面积应有“重量”，通常占画面 `6–15%`，而不是几个很小的状态方块。

### 2.5 有机而非粗糙

“手绘感”不是抖动路径或随意不齐。它来自有控制的曲率和明确的粗细关系：

- 外轮廓要少，曲线要长；每一段都服务于总姿态。
- 不绘制噪点、铅笔纹、刷毛、随机波浪或假纸张纹理。
- 没有理由的底线、星点、光晕和背景圆都删除。
- 线与线相交时，要有明确的覆盖顺序或留白，不让交点变脏。
- 如果一条线不能说明动作、结构或节奏，它就不该存在。

## 3. 将来重做“问卷”黑底主视觉的正确方法

不要再画一个完整笔记本。概念应是：**一笔确认，让人的表达被认真记录。**

建议的制作顺序：

1. 先用一条厚白色笔势画出“落笔后向外展开”的弧线，它既像一页被打开的纸，也像一次被接住的表达。
2. 只保留一个不完整的确认形状，例如一条被白线围出的勾，或一段从笔势中生长出来的弧；不画三行清单。
3. 把一枚陶土橙圆放在笔势的重心上方或转折处，让它像被看见的观点，而不是通知红点。
4. 如确实需要第二色，只以一小块鼠尾草色托住动作起点；不用黄、绿、橙三色并列。
5. 不加地面线、不加卡片框、不加漂浮阴影；让黑底和负空间完成“高级感”。

静态稿通过后，再考虑极慢的笔势显现或色块呼吸。动画不能被用来补救构图。

## 4. 陈纸功能线绘的保留规则

这类插画不追求黑底主视觉的雕塑感，但也不能潦草：

- `360 × 360` 画布中，主轮廓约 `4px`、结构线约 `2.5px`、地面线约 `2.3px`。
- 每张仍要有一个主物件、一个动作辅助线和一个低对比地面线。
- 用一块主填色（鼠尾草或黄铜）和一处陶土橙小信号即可。
- 礼盒、Coins、购物车、嫩芽的现有方向可作为参考；新增物件先复用这些比例和圆角，不随意改成 Lucide、Emoji 或贴纸风。
- 在浅底中，完整物件与功能识别优先于抽象隐喻。

## 5. 动效语法

### 功能线绘

- 允许 `7–9s`、`2–3px` 的轻微漂移，或一个一次性的勾选出现。
- 动画应该只说明动作，不制造注意力。

### 墨黑主视觉

- 最多一个动作：主笔势的轻微显现、色彩体块的缓慢进入，或一段线条的短暂描绘。
- 不做同步上下漂浮、弹跳、无限旋转、闪烁、粒子、光晕。
- 默认先验收静态稿；只有静态稿通过，动效才有资格出现。
- 一律支持 `prefers-reduced-motion: reduce`。

## 6. 出图前审稿门槛

任何一张黑底主视觉必须全部满足：

1. 不看标题也能感到一个明确的人本动作或关系。
2. 轮廓在 `160px` 缩略图中仍有独特剪影。
3. 主图形不是完整 UI 图标的反相版。
4. 只有一个色彩主体；颜色有构图重量，不是状态贴纸。
5. 线条数量已经删到不能再删，仍保留动作与节奏。
6. 没有地面线、渐变、投影、卡片框、装饰星点或无意义背景圆。
7. 静止时已足够好看；动画关闭后不失成立。

若有任意一项不通过，就回到草图阶段，不进入代码或部署流程。

## 7. 未来协作简报模板

以后每次需要新插画，先明确下面五项，再开始画：

```text
场景：功能线绘 / 墨黑签名主视觉
人本动词：例如“被认真记录”“抵达”“回应”
唯一英雄轮廓：一句话描述，不写功能清单
色彩主体：陶土橙 / 黄铜 / 鼠尾草，只选一项主色
是否需要动效：没有明确叙事需要时，默认不加
```

这份语法优先于“先画十二个图标”。先把一张图做到有识别度，再扩展成家族。
