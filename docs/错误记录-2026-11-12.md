# 错误记录 · 2026-11-12

只记今天真实发生的错，每条都有现象、原因、修法、以后怎么防。

## E-140 16:9 的框套竖屏视频，两边两条黑边
- 现象：竖屏片子放进 16:9 容器，左右大片黑。
- 原因：没看素材长宽比，直接用了嵌入代码里的 `padding-top:56.25%`。
- 修法：改成 9:16，再把框裁成 420×420。
- 以后：先确认素材比例，再定容器。

## E-141 改成 4:5 仍然黑边
- 现象：4:5 下左右还有黑边。
- 原因：素材是 9:16，4:5 仍比素材宽。
- 修法：9:16 iframe 放大到容器宽度的 178%，用 `overflow:hidden` 裁掉上下。
- 以后：裁切 = 内部按素材比例铺满 + 外部溢出隐藏，不是调容器比例了事。

## E-142 英文长句塞进 56px，折成三行
- 现象：`Independent thinking, clear judgement.` 在 56px 下三行，压垮整块。
- 原因：翻译没考虑行长，56px 一列只能放约 14 个拉丁字符。
- 修法：英文缩成 `Independent thinking.`（现为两行）。
- 以后：定字号同时算行长，翻译也要按行数验收。

## E-143 `white-space: nowrap` 把标题顶出屏幕
- 现象：英文标题横向溢出到视口外。
- 原因：为了“不换行”加了 nowrap，却没限制宽度。
- 修法：去掉 nowrap。
- 以后：不许用 nowrap 解决换行问题。

## E-144 把“Beyond the obvious”当成“独立思考，明辨是非”的翻译
- 现象：登录块出现首页标语，语义完全不对。
- 原因：把品牌标语当成了这句话的英文。
- 修法：中文用原句，英文直译。
- 以后：标语和正文分开管理，不互相借用。

## E-145 表单控件 54–72px，像海报不像表单
- 现象：按钮、输入框巨大。
- 原因：登录块继承了 `.home-atlas` 的大控件规格。
- 修法：卡片内控件统一 44px、圆角 8、内边距 16。
- 以后：表单控件用产品规格（40–48），不用营销按钮规格。

## E-146 深色出血大地球，“吓人”
- 现象：整段黑底 + 1500px 地球出血，观感像星球砸页面。
- 原因：把装饰当主角，对比度拉满。
- 修法：回到白底 + 极淡地平线（Stripe 的做法：地球是一张极淡线稿弧）。
- 以后：地球只做纹理或地平线，不做实物大球。

## E-147 22px 段落用 CSS 两栏，句子从中间断开
- 现象：“…cross-regional / opportunity…” 硬断。
- 原因：`columns:2` 按字符数机械分栏。
- 修法：改单栏（720）或整段 38px 顶格。
- 以后：分栏只在有语义断点（段落/小节）时用。

## E-148 38px 段落删了又加、加了又删
- 现象：同一段话在三版里出现/消失三次。
- 原因：每次只按当条指令改，没有固定的页面结构。
- 修法：写死结构：段落 → 地球 → 登录 → 收尾。
- 以后：动版式前先确认它在结构里的位置。

## E-149 中文页面里留了一句英文说明
- 现象：中文标语下面写着 `Your next step starts here.`
- 原因：文案按组件写死，没做语言分支。
- 修法：按语言给副标题。
- 以后：任何可见文案都要过三语检查。

## E-150 把“规范化重写”说成已完成，实际只是叠加覆盖
- 现象：说“已按规范改”，其实只是加了 overriding CSS。
- 原因：用补丁代替重构，且没有验证齐平。
- 修法：待重写（未完成，已列进交接文档）。
- 以后：说“做完”之前必须量一遍所有相关元素。
