# 错误记录（2026-11-11，本轮返工）

## E-101 改错代码副本
现象：所有改动都在线上看不到。
原因：本地有两份代码，`survey-panel`（无 git 的旧副本）和 `.tmp-changelog/fe`（真仓库）。我在旧副本上改、构建、看截图，全部无效。
教训：动手前先确认 `git remote -v` 和 `git log`；没有 `.git` 的目录一律当副本，不当源码。

## E-102 把内部动作放进了客户页面
现象：客户的研究工作台出现“发送合同/发报告/发布结果”。
原因：没区分管理端（内部）和研究端（客户）。这些是运营动作，客户只能签收。
教训：任何按钮先问“谁按”，客户页只出现客户自己的动作。

## E-103 指错入口
现象：说“管理员端在 /admin/client-projects”，但实际在用的是 `/admin` 的中文「项目与订单」。
原因：仓库里有两套管理页（英文 AdminBusinessProjects、中文 AdminList），我只改了前者就宣布完成。
教训：说“入口在哪”之前，先按用户的截图确认是哪个路由。

## E-104 页签只换样式不筛数据
现象：「项目与订单」四个页签点哪个都一样。
原因：`AdminList` 里 `tab` 只控制 `is-active`，从未参与过滤。
修复：模块提供 `filterRows(rows, tab)`，列表按它截取。

## E-105 一行塞六个字段
现象：项目列表读起来挤。
原因：名称、状态、形式、回收、日期、动作、菜单全在一行。
修复：先改两行，后按 YouGov 改成卡片；状态徽标进卡片头，描述移入详情。

## E-106 表格语言混排
现象：`Projects | 状态 | 形式 | 回收 | 创建`。
原因：部分表头走英文文案，部分走代码里的中文兜底。
修复：表头标签按当前语言统一取值。

## E-107 图表里硬编码中文
现象：英文界面环形图出现“其他”。
原因：`ResultsChart` 里写死 `'其他'`。
修复：改为 `otherLabel` 参数，按语言传入。

## E-108 崩溃页不给原因
现象：工作台崩溃后只有一个“Reload”。
修复：`ErrorBoundary` 把错误信息直接显示在页面上，方便下一轮定位。

## E-109 改完不回滚验证就宣布上线
现象：多次说“已上线”，实际包没变（构建排队/失败）。
教训：每次发布后必须取线上 `index-*.js` 并 grep 本次字符串；哈希没变就是没上线。

## E-110 用整页刷新代替状态更新
现象：操作完成后 `window.location.reload()`。
修复：工作台改为 `reloadKey` 触发数据重取；管理端仍是刷新，待改。
