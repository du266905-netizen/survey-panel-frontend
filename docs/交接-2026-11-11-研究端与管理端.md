# 交接：研究端与管理端（2026-11-11）

仓库：`du266905-netizen/survey-panel-frontend`，本地工作副本 `.tmp-changelog/fe`，分支 `main`。
线上包以 `index-*.js` 为准，最后一次核对：`c7a5c0f` 已推送。

## 一、这一轮做了什么

### 研究端（客户可见）
- `BusinessResultsDashboard` 取代原结果页：KPI + 每题卡片 + 图表/表格切换 + 按题筛选 + 下载报告（打印成 PDF）+ 导出 CSV。
- `BusinessProjectSheet`：项目详情改成大弹窗，点列表「View details」打开；含状态、六步进度、四个数、交付物、记录。
- 项目列表改卡片（对标 YouGov）：状态、标题、类型·日期、回收进度、底部操作；不再显示研究目标长描述。
- 结果页门禁：`deliveryStatus` 不是 APPROVED/SENT 时显示“报告尚未发布 / 已不可用”，字段不存在时保持旧行为。
- 付款未确认不能发布问卷（`BusinessQuestionnaireStudio`）。

### 管理端（内部）
- `/admin/client-projects`：项目卡有「Project actions」。
- `/admin` 的「项目与订单」：每行有「操作」，打开同一套动作面板（发合同 / 请客户确认问卷 / 发报告 / 发布结果）。
- 页签真正按状态过滤（之前只换下划线）。

### 设置页
- Account / Team / Billing / Invoice / Budget / Help 共用 `BusinessSettingsLayout`：左栏 238px，挂载一次；顶栏与工作台一致；标题 28px。
